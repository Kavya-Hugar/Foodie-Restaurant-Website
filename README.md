# 🍽️ Foodie Restaurant Website

A modern and responsive restaurant website built using HTML, CSS, and JavaScript.

## 🌐 Live Demo

[Visit Foodie Restaurant Website](https://kavya-hugar.github.io/Foodie-Restaurant-Website/)

## ✨ Features

- Attractive homepage
- Responsive navigation bar
- Food menu with prices
- Add to cart functionality
- Increase and decrease item quantities
- Shopping cart with total price
- WhatsApp order functionality
- Table reservation form
- Restaurant offers
- Customer reviews
- Food gallery
- Contact information
- Mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 📂 Project Structure

```text
Foodie-Restaurant-Website/
│
├── index.html
├── style.css
├── script.js
└── 404.html
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
